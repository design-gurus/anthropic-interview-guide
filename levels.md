# Levels and seniority at Anthropic

The published sources behind this guide name no Anthropic level ladder, so this page does not list one. What the sources do report is how seniority changes the loop, how new graduates are hired, and how many years of experience some postings request. Ask your recruiter which level you are being considered for and which rounds that level adds.

## What the sources support

| Topic | What is reported |
|---|---|
| Level names | None are named in the sources, and this guide does not infer any |
| Effect on the loop | The exact set of stages depends on the role and the level |
| Senior roles | A system design round is reported as added for senior roles |
| New graduates | The loop has the same shape, with less weight on large system design |
| Years of experience | Applied AI Engineer postings ask for 4 or more years, and enterprise postings ask for 6 or more |
| Credentials | Anthropic states that it cares about what you can do, not where you learned it |

## How the loop changes with seniority

The coding rounds and the values round are reported for every candidate. The differences are in design and in the project conversation.

- **Early career.** Expect the written question, a recruiter screen, a technical screen, and an onsite loop. The values conversation is a real round for junior candidates as well.
- **Experienced engineers.** Expect a system design round in the first onsite loop. Expect also a technical project review, where interviewers ask about decisions, rejected alternatives, and numbers.
- **All levels.** The experiences and goals round is run by someone at manager level or above.

A technical project review rewards a project in which you made the decisions. Interviewers are reported to keep asking until they find the limit of your real involvement.

## New graduates

Anthropic is reported to hire people directly from university. It does not run a fixed annual graduate program with set application dates. Roles appear when a team needs them, so apply in the week a suitable role is posted.

Sources list the evidence that counts for an applicant with little work history:

- Published or preprinted research with a clear personal contribution.
- Open source software that has real users.
- A system you built and operated.
- An internship in which your work shipped.
- Clear technical writing.

Two strong items are reported to count for more than ten weak ones. A posting that asks for several years of experience is not always closed to you. Candidates report that strong project work is weighed against the stated number.

The written "Why Anthropic?" answer carries extra weight for a new graduate. With less work history, the quality of your reasoning is a larger part of the application. See [Behavioral interview](behavioral-interview.md).

## Machine learning background

Anthropic is reported to state that about half of its technical staff had no machine learning experience when they joined. Software Engineer and Applied AI roles do not require a machine learning background. The Research Engineer role is the exception, and it is reported to have a machine learning bar. See [Roles](roles.md).

## What this page does not cover

This guide gives no pay figures and no mapping from Anthropic levels to other companies. The sources support neither. If a recruiter names a level, ask what scope that level is expected to own. Scope means the size of the problems you are trusted to handle alone.
